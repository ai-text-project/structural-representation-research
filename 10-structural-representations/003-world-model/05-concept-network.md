# Concept Network

## Project

World Model Structural Representation

---

# Purpose

This document records the conceptual relationships observed within the frozen Representative Resource Set.

Unlike the Dependency Map, which records prerequisite relationships among functional modules, the Concept Network records semantic connectivity among recurring concepts.

The objective is not to define execution order.

Instead, it reveals how recurring concepts collectively organize the conceptual structure of the World Model.

---

# Observation Principle

Concepts are introduced only when they recur consistently across the representative resources.

Relationships represent conceptual connectivity rather than implementation dependency.

The Concept Network therefore complements the Module Map without replacing it.
