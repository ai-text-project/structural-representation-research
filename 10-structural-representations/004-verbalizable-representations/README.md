**Paper**

**Verbalizable Representations Form a Global Workspace in Language Models**

---

# Repository Purpose

This repository externalizes the organizational architecture of the paper **Verbalizable Representations Form a Global Workspace in Language Models** using the Structural Representation Methodology.

Unlike the original paper, which combines theoretical discussion, experimental evidence, and practical applications, this repository progressively reorganizes the paper into reusable structural assets.

The objective is not to summarize the paper.

The objective is not to reinterpret its scientific claims.

Instead,

this repository identifies, externalizes, validates, and preserves the organizational architecture embedded within the paper.

The completed Structural Representation is intended to function as a reusable architectural resource for future Comparative Observation.
