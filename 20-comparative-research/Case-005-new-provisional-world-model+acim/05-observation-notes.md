A material control introduced before full comparison was:

```text

      ↓
```

# 4. Relation Before Description

Another control principle was:

> **Compare relations before descriptive similarity.**

For example, comparison should prefer:

```text
A1 → A2
      ↕
B1 → B2
```

over:

```text

```

This reduced the risk of:

- label matching;
- semantic analogy;
- conceptual over-reading;
- forced one-to-one mapping.
