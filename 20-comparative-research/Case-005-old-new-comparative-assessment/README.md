# Purpose

This repository records the controlled comparative assessment between:

> **Old Case 005 — World Model × ACIM**

and:

> **New Independent Case 005 — World Model × ACIM**

The purpose is not to retroactively correct the Old Case.

The central governing principle is:

> **Compare the Cases that were actually formed, not hypothetical completed versions of them.**

# Comparative Status Categories

The final assessment uses six principal categories:

### PRESERVED

A materially comparable Legacy observation remains supported in New independent analysis.

### RECLASSIFIED

The Legacy observation remains relevant, but its level, scope, responsibility, or evidential strength changes.

### NON-REPRODUCED

A formed Legacy observation is not independently reproduced in the same structural form.

### NEW-FORMED / LEGACY-UNDETERMINED

New explicitly forms a later distinction for which Legacy contains a relevant precursor but no determining judgment.

### STAGE-UNAVAILABLE

New reaches an analytical responsibility for which no materially comparable Legacy stage was formed.

### NOT ESTABLISHED

The current evidence does not justify the stronger proposed conclusion.
